# 大大 · AI 开发者

专注把 LLM 接进实际业务：从知识检索、Agent 工作流到语音交互和企业应用。

主要使用 Python、TypeScript、React / Next.js，关注本地模型接入、可追溯的知识检索，以及可交付的产品体验。

## 代表项目

| 项目 | 方向 | 内容 |
| --- | --- | --- |
| [电力 AI 标书系统](https://github.com/sunShineLoveMe/ai_bidding_power_grid) | 企业文档智能 | 招标文件解析、RAG 知识库、AI 辅助编写、合规检查与 DOCX 导出 |
| [本地 RAG × Dify](https://github.com/sunShineLoveMe/local-rag-bge3-chroma-dify) | 知识检索 | Ollama / BGE-M3、Chroma、FastAPI 与 Dify 外部知识库接口 |
| [AnyLLM × LangGraph](https://github.com/sunShineLoveMe/anyllm-fullstack-langgraph-quickstart) | Agent 工作流 | 基于 Gemini 开源示例改造，接入 OpenAI 兼容模型，探索搜索与研究流程 |
| [Voicerly](https://github.com/sunShineLoveMe/Voicerly) | 语音应用 | 基于 VoxCPM 的语音合成应用，含音频交互、账号与积分模块 |
| [异构 AI 算力调度演示](https://github.com/sunShineLoveMe/heterogeneous-ai-compute) | AI 基础设施 | 资源管理、推理路由、智能调度与故障恢复的本地仿真演示 |
| [Argus AI 订单分析](https://github.com/sunShineLoveMe/order-monitor-panel) | 业务自动化 | 订单监测与分析应用，集成 n8n 工作流与实时数据交互 |

各项目的安装方式、配置要求和实现范围见仓库 README；原型与仿真能力会明确标注。
